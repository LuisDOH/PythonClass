# Como navegar en el repositorio

* En este repositorio usted encontrada varias carpetas, cada una corresponde a un tema en particular, y dentro podria encontrarse otra carpeta o directamente los archivos. 
<img width="970" height="551" alt="image" src="https://github.com/user-attachments/assets/74c9a951-4a12-4d3d-ae58-29e98fcc4bc4" />

* Si damos click por ejemplo a la carpete `Variables`, nos aparecera una nueva lista con todos los archivos que estan dentro de esta carpeta.

<img width="1063" height="370" alt="image" src="https://github.com/user-attachments/assets/bbbf7c73-353e-4ad1-b8f4-2699ba2b7028" />
> Los archivos que terminan con `.md` siempre contendran información que explique algún tema en particular. Tambien puede haber archivos con terminación `.py`, estos archivos son hojas de código como las que usted hace en VisualStudio Code.


* Para regresar al listado del inicio, solo hay que dar click en la palabra Python Class y esto lo llevara de regreso a donde se encuentran todas las carpetas. Tambien usar la flecha de ir hacia atras en su navegador.
